# Budget Manager

## Description
A simple console-based budget management application built in Java.
Allows users to track their expenses and income by category.

## Features
- Add expenses and income with custom categories
- Remove specific expenses and income entries
- Display summary of all expenses and income per category
- View all unique categories from both expenses and income
- Input validation and error handling

## Requirements
- Java 17+

## How to run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run `Main.java`

## Technologies
- Java
- Maven
